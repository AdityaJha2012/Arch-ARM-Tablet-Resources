# Arch ARM Tablet Resources 0.1.0

Download **Arch-ARM-Tablet-Resources-v0.1.0.zip**, extract it and open **docs/START-HERE.md**.

The ZIP contains the guides, source catalog, source archives and SHA256 checksums. You do not need to download separate archive parts or join files.

This is a resource pack for developers. **It is not an ISO, a flashable tablet image or a finished driver pack.** Tablet hardware is unverified and the exact model is still unknown.

The upstream kernel and community source archives belong to their original authors. Preserve their licenses. The historical 5.4 kernel and newer modules are separate reference baselines, not a matched build system. Four source repositories referenced by the community manifests were unavailable publicly during collection.

The Arch Linux ARM base filesystem remains available through its official signed download service, linked in the guide. This pack does not include proprietary Samsung firmware.
