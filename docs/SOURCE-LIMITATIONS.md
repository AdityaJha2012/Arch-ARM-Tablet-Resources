# Source limitations and licensing

This is an independent resource collection, not an official Samsung, Arch Linux ARM or Bodh OS release. Galaxy OS was cancelled. No private Bodh OS source or history is included.

The source catalog records upstream URLs, branches and commit hashes. Release archives retain upstream source layouts and license files. Our MIT license applies only to our original documentation and helper code.

The collection does not redistribute stock Samsung firmware, extracted proprietary blobs, modem calibration data, credentials, device identifiers or prebuilt tablet recovery images. Obtain any required firmware through its authorized source and check its individual license before redistribution.

GitHub's automatic license detection is incomplete. A missing detected SPDX license does not establish permission for an entire repository. Archives selected for release must have a recognized upstream license or clear licensing in their source files. References with unclear redistribution terms remain links only. Keep and comply with each file's actual terms when using or modifying it.

The community's manifests are research references. A manifest is not proof that its repositories, branches, XML syntax or complete build dependencies are currently usable. Missing source references are listed in the generated inventory. They must be resolved before a reproducible build is possible. WiFi model configuration is not a 5G configuration.

Arch Linux ARM root filesystem binaries remain linked to the official signed download. No local kernel build, VM boot, tablet flash or tablet hardware test has been performed for this collection.

Some official and community websites may reject automated requests or redirect. The catalog distinguishes a source reviewed through its maintainer page/API from an endpoint whose content could not be retrieved. Website availability is not hardware validation.
